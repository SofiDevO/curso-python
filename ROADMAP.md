# Roadmap de Estudio: Fundamentos de Python

Este documento enlista los temas esenciales para aprender las bases de Python, siguiendo la ruta recomendada por [roadmap.sh](https://roadmap.sh/python).

## Aprender las Bases (Learn the Basics)

El orden sugerido de estudio es el siguiente:

- [x] **Sintaxis Básica (Basic Syntax)**
    *   Entender la estructura del código, indentación y comentarios.
- [x] **Variables y Tipos de Datos (Variables and Data Types)**
    *   Números (Integers, Floats)
    *   Strings
    *   Booleanos
- [ ] **Condicionales (Conditionals)**
    *   `if`, `elif`, `else`
- [ ] **Conversión de Tipos (Type Casting)**
    *   Convertir entre tipos de datos (ej. `int()`, `str()`, `float()`).
- [ ] **Excepciones (Exceptions)**
    *   Manejo de errores con `try`, `except`.
- [ ] **Funciones (Functions)**
    *   Definición de funciones.
    *   Funciones integradas (Built-in Functions).
- [ ] **Listas, Tuplas, Sets y Diccionarios**
    *   Estructuras de datos fundamentales en Python.
- [ ] **Bucles (Loops)**
    *   `for` loops
    *   `while` loops
